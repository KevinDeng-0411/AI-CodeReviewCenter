# C3 交接运行手册

本页服务于没有参与 C1/C2 实施的接手者。它不增加产品能力；所有命令都可从根
`README.md` 找到，机器结论最终只认 C3 Evidence。

## 1. 环境

需要 Docker Desktop/Compose、Python 3.12、uv、Node.js/npm 和 Chrome。普通冻结验证
使用 fake LLM/embedder，不需要真实 DeepSeek key，也不会下载 bge-m3。Docker daemon
必须已启动，仓库工作区必须干净。

## 2. 一键复现

从仓库根运行：

```bash
./codeaware-py/scripts/verify_current_release.sh
```

预期最后出现：

```text
[C3 VERIFY] PASS release=0.1.0
[C3 VERIFY] exact cleanup confirmed repository_status_unchanged=true development_resources_unchanged=true
```

该命令覆盖依赖锁、Compose、C1/C2 Evidence、OpenAPI、secret/path hygiene、fresh
bootstrap、后端全量/覆盖率、API E2E、固定 Chat/RAG 指标、前端 test/lint/build 与
七域 browser E2E。

## 3. 聚焦交接演示

```bash
./codeaware-py/scripts/demo_c3_handoff.sh
```

预期看到七域 `[PASS]`、`[C3 METRICS]`、C2 live evidence 重新校验以及
`[C3 HANDOFF] PASS`。本演示不重复调用真实模型；真实依赖结论来自已提交且哈希有效的
C2 live smoke。

## 4. 回退演练

```bash
./codeaware-py/scripts/verify_c3_rollback.sh
```

该脚本在一次性数据库验证 Alembic 往返和逻辑备份/恢复，再在 detached 临时 worktree
复现 C2 七域基线。它不得切换、reset 或清理当前工作区，也不得连接开发数据库。最后应
出现：

```text
[C3 ROLLBACK] PASS worktree_removed=true stacks_removed=true backup_restore=true main_unchanged=true
```

## 5. 结果阅读

- 公开 HTTP 契约：`codeaware-py/openapi/current-release.json`
- 发布说明：`docs/releases/0.1.0.md`
- 自动 Evidence：`docs/roadmap/current-release/evidence/C3/manifest.json`
- 当前限制：根 `README.md` 的“当前限制”
- 下一阶段：C4 BM25；Agent 仍锁定

任何必需命令失败都不能以口头说明替代。修复后需重新运行受影响命令；若已形成 C3
Evidence，则重新采集并通过 `supersedes_manifest_sha256` 替换。
